# 개인 포트폴리오 실습 프로젝트

이 프로젝트는 개발 경험이 없는 학생의 GitHub Copilot 앱 따라하기 실습용입니다.
별도 설치·회원가입 기능·외부 API 없이 HTML, CSS, JavaScript로 동작합니다.

## 시작하기
1. 압축 파일을 풀고 `index.html`을 Edge 또는 Chrome으로 엽니다.
2. 소개와 연습용 작품 3개가 보이는지 확인합니다.
3. 수업에서는 강사의 템플릿 저장소를 본인 계정에 만든 뒤 Copilot 앱으로 복제하여 사용합니다.

## 파일의 역할
- `index.html`: 화면의 기본 틀
- `styles.css`: 색상·간격·배치
- `profile.js`: 소개와 작품 정보
- `app.js`: 소개와 작품을 화면에 표시하는 동작
- `assets/`: 직접 만든 연습용 그림 3개
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 게시하기 위한 파일

## 배포하기
본인 저장소의 main에 파일을 커밋·푸시합니다.
GitHub Settings > Pages > Deploy from a branch > main > /(root) > Save를 선택합니다.
배포가 완료되면 Visit site의 실제 주소를 엽니다.
이 폴더의 파일을 저장소 최상위에 둡니다. 파일 경로는 상대 경로를 유지합니다.

## 예시 작품과 개인화
그림과 설명은 실제 학생 작품이 아닌 직접 제작한 연습용 예시입니다.
수업 후 자신의 작품 이미지와 설명으로 교체할 수 있습니다.
공개 가능한 소개와 작품만 사용하고, 다른 사람의 개인정보는 넣지 않습니다.
